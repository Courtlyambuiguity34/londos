# ADR-0013: bounded conversational design proposals

P10 implementation, 2026-10-06, Africa/Kampala. Preserve applied 001–016 and all prior finance, privacy, publication and worker boundaries. AI is private authoring assistance; public rendering reads validated canonical LSS and makes no provider calls.

Fresh native design authority is checked before assembling minimal context, after external work and before applying a proposal. Only current shop design, public shop labels and bounded active catalogue IDs/names are sent; text is explicitly untrusted data. No contact values, member identity, evidence, credentials, filesystem/database access or tools enter provider context. Supported simple edits are deterministic and require zero remote calls. Provider output is a closed bounded intent, compiled through the existing LSS schema/budgets and canonical owned-reference validator. No executable code or automatic publication is allowed.

Gemini is initial when configured. OpenAI is selective review or explicitly enabled outage fallback; quota/rate-limit signals never trigger credential cycling or another provider to evade limits. Configured Gemini slots support explicit selection and optional authentication-only failover, never quota rotation. Each request permits at most three attempts, one bounded repair/transient retry and selective review, with finite request/output/context limits, cancellation, deadlines and shared durable cooldowns. Fixed HTTPS destinations, redirect rejection and bounded response readers protect transport. Credentials and endpoint/model selection are server-owned.

Remote processing defaults off and requires explicit merchant consent, configured credentials/model and explicit integer price estimates. Admission serializes durable per-shop daily request/token/estimated-cost budgets and shop/global concurrency. Reservations conservatively cover all allowed calls and are retained for the day even when usage is missing or a request fails; they are estimates, not bills or merchant charges. Provider-reported usage is recorded separately. No supplied price or configured capability is evidence of live access or billing. Live contract checks run only against configured authorized accounts, and missing accounts remain an explicit external validation gap.

Request keys/fingerprints are immutable per actor; identical retries do not repeat calls, changed payloads conflict. No raw instruction/prompt, invalid provider response or provider error body is retained in database/logs. Only a bounded validated structured candidate remains for up to 15 minutes; applying/rejecting/cancelling/expiring scrubs it. Minimal receipts and redacted attempts/usage remain. Existing lease-fenced maintenance performs bounded cleanup. A stopped worker leaves physical cleanup pending, while reads/apply enforce expiry immediately. Production legal/metadata retention and physical backup handling remain release obligations.

Applying requires original requester, current fresh design authority, explicit confirmation, matching proposal/base-design version and unchanged bounded canonical context/reference versions. Proposal result, immutable new draft and minimal audit commit atomically. Application never publishes. A separate existing fresh publication command revalidates references and eligibility. Conflicts/revocation/expiry/failed repair/review cannot overwrite drafts or publish. Reviewer disagreement/unavailability is visible and requires separate merchant acknowledgment when a validated candidate is offered. Cancellation prevents future calls/candidate application; already-admitted external usage is not promised a refund or retroactive cancellation.

Verification must cover native HTTP/HTML/Flight isolation, deterministic zero calls, hostile/malformed/oversized output, foreign references, changed catalogue/revisions, real serialization waits, idempotent concurrency, shared budgets/cooldowns, cancellation/deadlines, transport redaction, failed SQL rollback, worker cleanup and accessible preview/confirm/publish flows. Live credentials are currently absent; local fake transports cannot certify provider access, model quality, price accuracy or a complete live AI release.
