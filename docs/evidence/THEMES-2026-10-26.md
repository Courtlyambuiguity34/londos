## Implemented

- Six original modular JSON themes: Atelier, Terrain, Harvest, Signal, Studio
  and Pulse. Automatic registry generation runs before dev/build. Definitions
  use bounded layout/type/palette tokens and contrast validation.
- A visual theme picker; merchant-owned branding/copy/sections remain in the
  existing versioned design. Supported named-theme assistant commands compile
  locally, without a provider call or direct publication.
- Image-led shop entrances, collection tiles, product cards and dedicated
  department/product destinations, preserving scoped preview navigation.
- Exact duplicate sections render once. Draft cleanup is explicit; new
  narrative fields start empty instead of repeatedly inserting welcome copy.
- Narrative-only published designs can display a bounded current owned
  catalogue. Existing archival, tenancy, moderation and publication gates apply.
- Focused catalogue/designer/landlord communications panels with retained input,
  keyboard tab navigation and responsive paired form fields.
- [Merchant/design guide](../STOREFRONT-THEMES.md) and
  [one-file theme extension instructions](../../src/modules/shop-themes/README.md).

No SQL migration, dependency, credential or environment-variable change is
required. Readiness remains migration036. No real tenant/product/financial data
was altered and no production deployment or provider delivery was performed.
