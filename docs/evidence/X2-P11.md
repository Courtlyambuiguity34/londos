## Delivered contracts

[ADR-0014](../ADR/0014-bounded-semantic-spaces-and-catalogue-pagination.md) closes the bounded semantic registry: entrance, display, department, collection, story, offer, service desk, gallery and contact, retaining the legacy products shape. Native forms, AI compiler, current reference checks, private preview and public renderer share the same strict version-1 contract. Eight spaces, 32 cards, 7,000 bytes and three canonical contact actions remain hard limits. Gallery references require owned ready media and alt text; offers are plain merchant copy. No arbitrary HTML/CSS/query language or automatic financial effect is introduced. AI remains private and cannot publish.

Department pages now reach the full catalogue through 20-row keyset pages with a lookahead. Canonical bounded cursors bind shop/department, version, generation and `(position,id)`; repeatable-read SQL and transactional per-shop statement counters prevent silent continuation after mutations. Wrong-scope/malformed cursors reject; stale cursors offer an explicit restart. All 100 bounded departments remain navigable. Metadata/content share identical cursor-aware request-local cache arguments, preventing duplicate canonical assembly. Changes beyond the AI context's first 32 products also invalidate stale proposals. Failed images preserve canonical text and expose an accessible retry.

The manual picker is deliberately bounded to the first 32 current products plus existing design references (at most 64); catalogue reordering changes selection. Video/3D, designer SDKs, arbitrary tags, advanced typo/multilingual search and richer financial arrangements are not claimed by this registry.

## Isolated failures and recovery

Two independent compiled webs and one worker share PostgreSQL. Urgent tenancy/moderation/publication/hold mutations each deny HTML and ready media on both processes, restore both and leave another shop available. Each following experiment is restored before the next:

- Media blob relation unavailable: shop text remains available, variant denies, restored genuine bytes are verified. Browser retry also restores a normalized image.
- Analytics relation unavailable: capture returns 202, canonical writes/reads survive, restoration records the event.
- Dedicated ephemeral search role loses product SELECT: actual SQL permission failure leaves both ordinary shop pools usable; restored grant restores search. This does not claim an independently deployed search service.
- Temporary product-write rejection: actual native command rolls back product version/price and generation; reads survive, removing the trigger restores writes.
- Actual worker stop: media and old schema-1 profile job remain durably queued; restart normalizes media and records exactly one profile effect, recovering in 628.46 ms.
- Injected fixture AI unavailable: manual draft/public reads survive; recovery returns a validated candidate. No live request occurs.
- No shared response cache is configured: discard/restart the second process and verify canonical reading. Redis/CDN outage cannot be certified without those adapters.

All destructive fixture manipulations affect only the generated guarded database; cleanup removes its own database/processes/role. The main Docker volume/private accounts are preserved.
