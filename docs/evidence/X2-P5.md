## Corrections during implementation

Real PostgreSQL exposed inconsistent UUID/text parameter inference in upload creation; explicit UUID casting fixed it. The first independent test-database setup correctly rejected an environment/connection identity mismatch; the harness now supplies the matching guarded test identity and explicit foreign fixtures.

The test database teardown initially force-dropped before PostgreSQL observed all closing sockets, producing an unhandled idle-connection error. Cleanup now waits briefly for those connections to disappear and drops without force. Vitest's unhandled-error hook removes credential-bearing driver context while retaining the failure, message and code; it never returns false or suppresses the test failure. The original error serialization exposed a local development DB password; that password was rotated and a new connection verified, preserving canonical records and application account credentials. No value is retained in this evidence or committed.

Full axe checks found the existing preview notice outside a landmark. It now has a named region, and its copy accurately permits the separate new enquiry surface. Generated `dist` output is excluded from source linting, matching `.next` and the existing ignored build artifacts; application/test rules remain enforced. Notification fanout rejects and rolls back beyond the development limit rather than silently skipping owners.
